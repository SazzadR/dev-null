# 🕳️ dev-null

> *"A graveyard of codes."*

A dumping ground for throwaway scripts, practice demos, and random experiments.

## 🤷‍♂️ What is this?
Named after the infamous Unix `/dev/null`, this repository is a sandbox. I use it to test out new libraries, practice coding concepts, reproduce bugs, and write quick scripts that don't belong in a real project.

Once the code has served its purpose, it either sits here collecting digital dust or gets deleted.

## ⚠️ Disclaimer
- **Zero Maintenance:** Nothing here is actively updated or maintained.
- **Chaos Expected:** Expect unfinished code, questionable decisions, TODOs that will never be done, and the occasional `print("here")`.
- **Temporary:** Expect random deletions, restructures, and force-pushes.
- **Not for Production:** Seriously, don't copy-paste this into your main codebase without checking it first.

## 📂 Structure
There are no strict rules. Folders are usually created on a whim based on whatever language, framework, or concept I am messing with that day.
